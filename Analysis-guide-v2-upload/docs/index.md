# 広がったX線源の解析ガイド

このガイドは、超新星残骸や銀河団のように空間的に広がったX線源を、公開データから解析するための日本語の道案内です。現在は **Chandra/ACIS** と **XRISM/Resolve・Xtend** を扱います。点源、グレーティング分光、時間変動の解析を網羅するガイドではありません。それらは[対象外の解析と公式ガイド](other-analyses.md)から探せます。

広がった線源では、検出器上の位置によって露出や応答が変わります。画像で明るく見える部分が、天体そのものの構造とは限りません。また、対象が視野の大部分を占めると、線源のない場所を Background 領域として選ぶことも難しくなります。**領域、Background、応答をどう選んだか**が科学結果を左右するため、コマンドだけでなく判断の理由も説明します。この構成は [CIAO の Extended Sources Analysis Guide](https://cxc.cfa.harvard.edu/ciao/guides/esa.html) に倣っています。

## 読む順番

1. [解析を始める前に](preparation.md)で、データ、校正、作業場所を確認します。
2. [Chandra/ACIS](chandra.md)または[XRISM](xrism.md)で、観測から画像、領域、スペクトル、応答を作る流れをたどります。
3. [スペクトル解析と結果の確認](spectra.md)で、背景と応答を対応づけ、解析結果を点検します。

このサイトは公式マニュアルの翻訳や置き換えではありません。公式ガイドは観測モードごとの分岐、パラメータ、既知の問題を随時更新します。各作業のリンク先で、**使用するソフトと校正の版に合った手順**を確認してください。掲載する ObsID やファイル名は操作を説明するための例です。自分のデータではそのまま使わず、観測情報とファイルのヘッダーを確認して置き換えます。

## コマンドの見方

端末に入力するコマンドは `sh` のコードブロックに、XSELECT と XSPEC の内部で入力するものは別のコードブロックに載せます。`<EVENT>` のような記号は自分のファイル名に置き換えます。**入力例の前後にある「なぜ」「何を確認するか」も読んでください。** 解析対象の明るさ、広がり、観測モードによって、適切な領域や応答は変わります。
