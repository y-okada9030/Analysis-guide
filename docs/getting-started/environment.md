# 解析環境

このガイドの実行には、対象に応じて SAOImage DS9、HEASoft/XSPEC、CIAO、Chandra または XRISM CALDB が必要です。導入時は [HEASoft 公式ダウンロード](https://heasarc.gsfc.nasa.gov/docs/software/lheasoft/)、[CIAO 公式ダウンロード](https://cxc.cfa.harvard.edu/ciao/download/)、[XRISM ABC Guide の環境章](https://heasarc.gsfc.nasa.gov/docs/xrism/analysis/abc_guide/) を参照してください。Mac、特に Apple Silicon では各配布版の対応状況を確認します。

解析日の公式版と CALDB を記録し、CIAO と HEASoft を同一 shell に重ねて使う際は実際に動いている tool と `PFILES` などを確認してください。Chandra の作業は CIAO、XRISM の作業は HEASoft の公式手順を基本にします。
