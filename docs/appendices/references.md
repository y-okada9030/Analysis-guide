# 公式資料・出典

2026-09-15 に確認しました。版や校正は変わるため、解析日には各サイトの更新履歴を見てください。実行コマンドの基礎は以下の**公式一次資料**です。

## Chandra / CIAO

- [CIAO 4.18 Quick Start Guide](https://cxc.cfa.harvard.edu/ciao/guides/quick_start.html)：ObsID 取得、`chandra_repro`、DS9、`specextract` の公式例。
- [アーカイブ取得スレッド](https://cxc.cfa.harvard.edu/ciao/threads/archivedownload/) と [`download_chandra_obsid` Ahelp](https://cxc.cfa.harvard.edu/ciao/ahelp/download_chandra_obsid.html)。
- [`specextract` Ahelp](https://cxc.cfa.harvard.edu/ciao/ahelp/specextract.html)、[点源スレッド](https://cxc.cfa.harvard.edu/ciao/threads/pointlike/)、[拡散源スレッド](https://cxc.cfa.harvard.edu/ciao/threads/extended/)。
- [`fluximage` Ahelp](https://cxc.cfa.harvard.edu/ciao/ahelp/fluximage.html)、[`combine_spectra` Ahelp](https://cxc.cfa.harvard.edu/ciao/ahelp/combine_spectra.html)。

## XRISM / HEASoft

- [XRISM ABC Data Reduction Guide v2.0（2026-06-12）](https://heasarc.gsfc.nasa.gov/docs/xrism/analysis/abc_guide/)：本文の XRISM 主資料。
- [ABC Guide Resolve](https://heasarc.gsfc.nasa.gov/docs/xrism/analysis/abc_guide/Resolve_Data_Analysis.html) と [Xtend](https://heasarc.gsfc.nasa.gov/docs/xrism/analysis/abc_guide/Xtend_Data_Analysis.html)：抽出、追加 screening、応答、背景。
- [XRISM Quick-Start Guide v3.2 と既知の workaround](https://heasarc.gsfc.nasa.gov/docs/xrism/analysis/quickstart/)：ABC Guide と現行 HEASoft 版を照合する補助資料。
- [HEASoft](https://heasarc.gsfc.nasa.gov/docs/software/lheasoft/) と [XSPEC 公式マニュアル](https://heasarc.gsfc.nasa.gov/docs/software/xspec/manual/)：共通フィットツール。
