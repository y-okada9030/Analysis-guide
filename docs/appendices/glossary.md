# 用語

| 用語 | 意味 |
| --- | --- |
| ObsID | 一つの観測を識別する ID |
| EVT | 個々の検出事象の一覧 |
| GTI | Good Time Interval。解析に使う時間範囲 |
| PI | 校正されたエネルギー相当のチャンネル |
| PHA/PI spectrum | チャンネルごとの事象数 |
| RMF | エネルギーから検出チャンネルへの再分配 |
| ARF | エネルギーに対する有効面積 |
| RSP | RMF と有効面積情報を統合した応答 |
| PSF | 点状線源の画像上の広がり |
| NXB | 検出器・粒子に由来する非 X線背景 |
| BACKSCAL | 線源・背景領域の面積換算用 FITS 値 |
