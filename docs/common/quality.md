# 品質確認

「ツールが終了した」だけで解析は完成しません。科学結果を使う前に、少なくとも次を照合します。

| 確認 | 理由 |
| --- | --- |
| 観測 ID・機器・モード | 別データや窓モードを混ぜない |
| GTI、grade、エネルギー選択 | スペクトルと応答の不一致を避ける |
| 領域を画像上で再表示 | 間違った座標系や周辺線源を発見する |
| 背景の形・時間・`BACKSCAL` | 過大/過小な差し引きを避ける |
| RMF/ARF の出典と適用範囲 | 古い校正や点源/拡散源の取り違えを避ける |
| モデル残差と物理的妥当性 | 見た目だけの良好な fit を避ける |

Chandra の複数 ObsID を扱うときは、観測ごとにスペクトル・応答・背景を作ってから、必要に応じて公式 `combine_spectra` または同時フィットを選びます。XRISM Resolve では grade とピクセルの選択を RMF/RSP に一致させ、Xtend では RMF に対応する ARF のエネルギー格子を用います。各機器の [公式更新情報](../appendices/references.md) を解析日に確認してください。
