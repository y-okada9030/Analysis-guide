# スペクトル解析と結果の確認

スペクトルファイルを作成しただけでは解析は完了しません。線源 PHA、背景 PHA、RMF、ARF が**同じ観測時刻・観測領域・イベント選択基準**に基づいていることを確認し、XSPEC で適切に対応づけた上でフィットを実施します。

## ファイルの対応関係を確認する

PHA ヘッダーの以下のキーワードを読み取ります：
- `BACKFILE`：背景 PHA ファイルへの参照
- `RESPFILE`：応答行列（RMF）への参照
- `ANCRFILE`：有効面積ファイル（ARF）への参照
- `BACKSCAL`：線源領域と背景領域の相対的な面積・有効面積の係数
- `EXPOSURE`：露出時間

`BACKSCAL` は線源領域と背景領域の面積比に関係するため、正確に設定されていることが重要です。

```sh
fkeyprint <SOURCE_PHA> BACKSCAL
fkeyprint <SOURCE_PHA> RESPFILE
fkeyprint <SOURCE_PHA> ANCRFILE
fkeyprint <SOURCE_PHA> BACKFILE
```

上記は HEASoft 環境での確認方法です。Chandra の場合、CIAO の `dmlist` や `dmkeypar` でもヘッダーを確認できます。背景ファイルが指定されていない場合は、その理由を明記します。

## XSPEC に読み込む

XSPEC は [公式マニュアル](https://heasarc.gsfc.nasa.gov/docs/software/xspec/manual/) に従います。PHA ヘッダーに背景・応答への正しい参照が書かれていれば、自動的に読み込まれます。

```sh
xspec
```

```text
data <SOURCE_PHA>
show data
plot data
```

ヘッダーの参照がない、または科学的な理由で別のファイルを使う場合は、対応する背景・応答を明示的に指定します。`<...>` で囲まれた部分を実在するファイル名に置き換えてください。

```text
backgrnd <BACKGROUND_PHA>
response <SOURCE_RMF>
arf <SOURCE_ARF>
show data
```

広がった線源のスペクトルは位置によって異なることがあります。熱的プラズマ、非熱的成分、吸収などどの成分を導入するかは、観測帯域と研究目的から判断します。

## 統計手法と背景の扱いを決める

カウント数が少ない帯域や高分解能の輝線を扱う際、見やすくするための過度なグルーピングで情報を失うことがあります。統計手法とチャンネル統合の方法を、フィット報告に記します。

複数の ObsID や異なるミッションのスペクトルを扱う際は、観測ごと・機器ごとの PHA、背景、RMF、ARF を個別に保持した上で同時フィットするか、公式手順に従って結合します。スペクトル結合の詳細は解析報告に含めます。

## フィット結果を検証する

フィット完了後、データとモデル、残差を表示します。特定の輝線やエネルギー帯に系統的な残差がある場合は、モデルの問題だけでなく、背景、応答、領域定義に誤りがないかを再確認します。

```text
plot ldata delchi
```

最終的に、元のイベントファイルと露出マップ上で領域を再表示し、以下を確認します：
- 観測ログと既知の問題の有無
- イベント選別（screening）の内容
- 背景の規格化の根拠
- 応答行列の生成条件
- フィット実行の記録

これらを解析報告書に記録することで、結果の再現性と信頼性が保証されます。
