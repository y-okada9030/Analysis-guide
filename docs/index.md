# 広がったX線源の解析ガイド

このガイドは、超新星残骸や銀河団のように空間的に広がったX線源を、公開データから解析するための日本語の道案内です。現在は **Chandra/ACIS** と **XRISM** （Resolve、Xtend）の imaging データを対象にしています。

広がった線源では、検出器上の位置によって露出や応答が変わります。画像で明るく見える部分が、天体そのものの構造とは限りません。また、スペクトルをフィットするには、粒子起源の検出器背景を正確に知る必要があります。このガイドでは、公式マニュアルの流れに沿いながら、広がった線源の解析で特に注意すべき点を日本語で整理しました。

## 読む順番

1. [解析を始める前に](preparation.md)で、データ、校正、作業場所を確認します。
2. [Chandra/ACIS](chandra.md)または[XRISM](xrism.md)で、観測から画像、領域、スペクトル、応答を作る流れをたどります。
3. [スペクトル解析と結果の確認](spectra.md)で、背景と応答を対応づけ、解析結果を点検します。

このサイトは公式マニュアルの翻訳や置き換えではありません。公式ガイドは観測モードごとの分岐、パラメータ、既知の問題を随時更新します。必ず各ツールのヘルプ、CIAO/HEASoft の Caveat ページ、および該当する Science Thread を参照して、最新の情報で解析してください。

## コマンドの見方

端末に入力するコマンドは `sh` のコードブロックに、XSELECT と XSPEC の内部で入力するものは別のコードブロックに載せます。`<EVENT>` のような記号は、実在するファイル名に置き換えてください。
