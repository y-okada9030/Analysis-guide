# 広がったX線源の解析ガイド

このガイドは、超新星残骸や銀河団のように空間的に広がったX線源を、公開データから解析するための日本語の手引きです。現在は **Chandra/ACIS** と **XRISM**（Resolve、Xtend）の imaging データを対象にしています。

広がった線源では、検出器上の位置によって露出や応答が変わります。画像で明るく見える部分が、天体そのものの構造とは限りません。また、スペクトル解析をするには、粒子起源の検出器背景を正確に理解する必要があります。このガイドでは、公式マニュアルの流れに沿いながら、広がった線源解析で特に注意すべき点を日本語で整理しました。

## 読む順番

1. [解析を始める前に](preparation.md)で、データ、校正、作業環境を確認します。
2. [Chandra/ACIS](chandra.md)または[XRISM](xrism.md)で、観測データから画像、領域、スペクトル、応答を作成する流れをたどります。
3. [スペクトル解析と結果の確認](spectra.md)で、背景と応答の対応を確認し、フィット結果を検証します。

このサイトは公式マニュアルの翻訳や代替ではありません。公式ガイドは観測モードごとの分岐、パラメータ、既知の問題を随時更新します。必ず各ツールのヘルプと現行の公式ドキュメントを参照してください。

## コマンドの見方

シェル（端末）に入力するコマンドは `sh` のコードブロックに、XSELECT と XSPEC の対話環境で入力するものは別のコードブロックに示します。`<EVENT>` や `<REGION>` のような `< >` で囲まれた記号は、実在するファイル名に置き換えてください。
